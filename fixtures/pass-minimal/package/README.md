# lintprobe

一个用于 ohpm-lint 测试的最小合规包。

## 安装

```bash
ohpm install @quizzyjoy/lintprobe
```

## 所需权限

无。

## 接口

### probe(): string

返回固定字符串。

## 示例

```ts
import { probe } from '@quizzyjoy/lintprobe';
probe();
```

## 约束与限制

支持 API 12 及以上。
